# Aurwave Website Information Architecture

## Main Navigation

The primary navigation should contain:

- Home
- Services
- Work
- About
- Contact

The navigation should remain simple.

Avoid large numbers of top-level menu items.

---

# Homepage Structure

The homepage should follow this flow:

1. Header
2. Hero
3. Trust / Introduction
4. Services
5. Selected Work
6. Why Aurwave
7. Process
8. Capabilities / Technology
9. Testimonial or Social Proof
10. Final CTA
11. Footer

---

# Content Flow Logic

The user journey should follow:

Attention
↓
Understanding
↓
Trust
↓
Capability
↓
Proof
↓
Process
↓
Conversion

The website should not ask the user to contact Aurwave before clearly explaining the value.

---

# Navigation Behavior

Desktop:

- Clean horizontal navigation
- Visible primary CTA

Mobile:

- Simple menu
- Clear close button
- Accessible interactions

Navigation animation should be fast and subtle.

---

# Footer Structure

Include:

- Logo
- Short company description
- Navigation
- Contact information
- Social links
- Copyright
- Legal links if required
