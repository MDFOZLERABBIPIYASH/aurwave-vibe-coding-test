# Aurwave Content Strategy

## Hero Section

The hero must immediately answer:

What does Aurwave do?

Recommended content structure:

Eyebrow:
Digital Design and Development Agency

Headline:
A clear, confident statement about building modern digital experiences.

Supporting text:
A short explanation of Aurwave's value.

Primary CTA:
Start a Project

Secondary CTA:
View Our Work

---

# Introduction Section

Purpose:

Give visitors a deeper understanding of Aurwave.

Content should explain:

- Who Aurwave is
- What problems it solves
- The type of work it creates

Keep paragraphs concise.

---

# Services Section

Each service should include:

- Service name
- Short description
- Optional capability list

Example services:

- Web Design
- Web Development
- UI/UX Design
- E-commerce Development
- Website Redesign
- Performance Optimization

Avoid long descriptions inside cards.

---

# Selected Work

Each project should communicate:

- Client or project name
- Industry
- Short description
- Services provided
- Visual preview

Project cards should be highly visual.

---

# Why Aurwave

This section should explain differentiation.

Possible themes:

- Strategy before execution
- Design and development together
- Performance-focused implementation
- Attention to detail
- Clear communication

Avoid generic statements such as:

"We are passionate about innovation."

Every statement should communicate actual value.

---

# Process

Recommended process:

01. Discover
02. Define
03. Design
04. Develop
05. Launch

Each stage should include a short explanation.

---

# Technology Section

Show technology capabilities without overwhelming visitors.

Example categories:

Frontend:
- React
- Next.js
- TypeScript

Styling:
- Tailwind CSS

Animation:
- Motion

Deployment:
- Vercel

Only show technologies Aurwave actually uses.

---

# Final CTA

The final CTA should be direct.

Example structure:

Headline:
Have a project in mind?

Supporting text:
Brief invitation to discuss the project.

CTA:
Start a Conversation
