# Naming Rules

Use descriptive lowercase names.

Examples:

aurwave-logo.svg
project-ecommerce-home.webp
web-development-service.webp

Avoid:

image1.png
final-final.png
new-image.jpg

---

# Image Optimization

Prefer modern formats.

Recommended:

- AVIF
- WebP
- SVG

Use PNG or JPEG only when necessary.

---

# Image Rules

Before adding an image:

- Optimize file size
- Use appropriate dimensions
- Add meaningful alt text
- Avoid duplicate files

---

# Asset Metadata

Important assets should have documented:

- Source
- License
- Usage
- Optimization status

Do not use copyrighted assets without permission.
