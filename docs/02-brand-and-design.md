# Aurwave Brand and Visual Design Guidelines

## Design Direction

The visual direction should be:

- Modern
- Minimal
- Editorial
- Premium
- Digital-first
- Structured
- Calm

The design should use whitespace as a major design element.

Do not fill every section with visual elements.

---

# Visual Personality

Aurwave should feel:

- Confident
- Intelligent
- Creative
- Refined
- Modern
- Approachable

Avoid:

- Excessive gradients
- Random glassmorphism
- Excessive rounded cards
- Excessive shadows
- Too many colors
- Decorative clutter
- Over-animation

---

# Typography

Typography should create strong hierarchy.

Use a modern sans-serif typeface.

Recommended approach:

## Display Typography

Used for:

- Hero headings
- Large statements
- Major section headings

Characteristics:

- Bold
- Clean
- Strong
- Large scale

## Body Typography

Used for:

- Paragraphs
- Service descriptions
- Supporting information

Characteristics:

- Highly readable
- Comfortable line height
- Clear spacing

---

# Typography Hierarchy

Recommended hierarchy:

H1
- Large
- Bold
- Maximum visual impact

H2
- Major section titles

H3
- Component and card titles

Body Large
- Important supporting content

Body
- Standard readable content

Small
- Labels and metadata

---

# Color System

Use a restrained color system.

Recommended structure:

Primary:
- Main brand color

Neutral:
- Background
- Surface
- Primary text
- Secondary text
- Borders

Accent:
- Used selectively for interaction and emphasis

Do not use multiple competing accent colors.

---

# Layout

Use a consistent grid system.

Recommended principles:

- Maximum content width
- Consistent horizontal padding
- Responsive spacing
- Clear alignment
- Strong visual rhythm

Desktop layout should feel spacious.

Mobile layout should prioritize readability and thumb-friendly interaction.

---

# Spacing System

Use a spacing scale.

Example:

4
8
12
16
24
32
48
64
96
128

Do not introduce arbitrary spacing values unless necessary.

All components should follow the spacing system.

---

# Buttons

Primary buttons should:

- Be visually clear
- Have strong contrast
- Have obvious hover states
- Have subtle animation
- Maintain accessible touch targets

Avoid excessive button styles.

Recommended:

- Primary
- Secondary
- Text link

---

# Visual Assets

Use:

- High-quality project images
- Clean illustrations when necessary
- Subtle abstract visual elements
- Product screenshots
- Website previews

Every asset must support the content.

Do not add images only to fill empty space.
