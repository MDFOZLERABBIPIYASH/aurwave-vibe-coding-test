# UI/UX Guidelines

## General Principle

Function before decoration.

Every visual element must serve one of these purposes:

- Communicate
- Guide
- Organize
- Provide feedback
- Improve interaction

---

# Hierarchy

Each section must have a clear hierarchy.

Recommended pattern:

Eyebrow
↓
Heading
↓
Supporting content
↓
Action

Do not give every element equal visual weight.

---

# Readability

Maintain:

- Comfortable line length
- Adequate line height
- Clear contrast
- Sufficient spacing

Avoid large blocks of text.

---

# Interaction

Interactive elements must provide feedback.

Examples:

- Hover
- Focus
- Active
- Loading
- Success
- Error

Never rely only on color to communicate important information.

---

# Accessibility

Target WCAG 2.2 AA where practical.

Requirements:

- Keyboard navigation
- Visible focus states
- Semantic HTML
- Proper heading hierarchy
- Alternative text
- Sufficient color contrast
- Reduced motion support

---

# Responsive Design

Design for:

- Mobile
- Tablet
- Laptop
- Desktop
- Large desktop

Do not simply shrink the desktop layout.

Mobile should be intentionally designed.

---

# Forms

Forms should:

- Be simple
- Clearly labeled
- Show validation errors
- Preserve user input
- Provide submission feedback

Required information should be minimized.
