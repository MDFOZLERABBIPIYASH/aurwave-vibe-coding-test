# Maintenance and Monitoring

## Regular AI Maintenance

Claude should periodically review:

- Dependency health
- Build status
- Test status
- Broken links
- Performance
- Accessibility
- Unused assets
- Unused dependencies

---

# Performance Review

Monitor:

- Page load speed
- Core Web Vitals
- JavaScript size
- Image size

---

# Error Management

When an error is detected:

1. Reproduce the problem
2. Identify the cause
3. Create the smallest safe fix
4. Add or update tests
5. Validate the build
6. Deploy through preview
7. Promote to production

---

# Documentation Maintenance

When architecture changes, update:

- Technical architecture
- Dependency documentation
- Testing documentation
- Deployment documentation

Documentation should reflect the actual project state.

---

# Maintenance Principle

Avoid large unnecessary rewrites.

Prefer:

- Small improvements
- Incremental refactoring
- Controlled dependency upgrades
